## Available Guides

### [Getting Access to Dremel Lab S3 Files via Globus](globus-access-guide.md)
A step-by-step guide for Dremel Lab members to set up Globus access to the lab's S3 storage. Covers authentication via UVA NetBadge, finding collections, and basic file operations.

**Time to complete:** 5-10 minutes  
**Prerequisites:** Active virginia.edu account
